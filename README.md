Django Event Management System

Project Setup

This project is developed using Django, a Python web framework, to manage events and related activities.

Technologies Used

* Python
* Django
* SQLite3
* HTML
* CSS
* Bootstrap

Project Structure

* manage.py – Django project management utility.
* config/ – Main project configuration.
* config/settings.py – Project settings and configuration.
* config/urls.py – Main URL routing.
* config/asgi.py – ASGI configuration.
* config/wsgi.py – WSGI configuration.
* events/ – Application responsible for event-related features.
* db.sqlite3 – SQLite database.

Setup Instructions

1. Install Python.
2. Create and activate a virtual environment.
3. Install Django.
4. Navigate to the project directory.
5. Run database migrations.
6. Start the Django development server.

Running the Project

python manage.py check
python manage.py runserver

Open the browser and visit:

http://127.0.0.1:8000/

Project Purpose

The Event Management System is designed to organize and manage events and provide event-related information.
